03

Proyecto estrella

Producto propio, en producción y con empresas facturando a diario.

Producto propio · En producción

EdFactura

edfactura.com

Plataforma SaaS multi-tenant de facturación online de alto rendimiento, diseñada para cumplir los lineamientos de facturación electrónica de la DGII (República Dominicana): emisión y recepción de comprobantes fiscales electrónicos (e-CF), estructuras XML normadas, firma con certificados digitales, contabilidad automatizada e inventario en tiempo real.

  • Cumplimiento fiscal: generación, firma y transmisión de e-CF conforme a las normas técnicas de la DGII, con control de estados y acuses.
  • Multi-tenant: múltiples empresas contribuyentes servidas desde una sola plataforma, con datos y permisos aislados por empresa.
  • Módulos integrados: contabilidad general, inventario, cuentas por cobrar y pagar, clientes y reportes fiscales sincronizados.
  • Mi rol: arquitectura, desarrollo full-stack, base de datos, hardening del servidor, despliegue y soporte de producción.
  • PHP / CodeIgniter 4
  • MySQL
  • XML e-CF
  • Certificados digitales
  • Multi-tenant
  • REST

public class ComprobanteFiscal : IComprobante
{
    public string Tipo => "e-CF 32";
    public decimal Total { get; set; }

    public async Task<Resultado> EmitirAsync()
    {
        // Firma, valida y transmite a la DGII
        var xml = firmador.Firmar(this);
        var res = await dgii.EnviarAsync(xml);

        return res.EsValido
            ? Resultado.Aprobado
            : Resultado.Rechazado(res.Errores);
    }
}
